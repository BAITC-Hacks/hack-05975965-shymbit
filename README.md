# hack-05975965-shymbit
Hackathon team repository for ShymBit

## AI Sana Challenge Hub

Русскоязычный MVP веб-платформы, которая помогает организациям публиковать образовательные задачи, уточнять их с помощью AI и находить студенческие команды.

### Frontend

Frontend находится в папке `frontend` и построен на React, TypeScript и Vite. Реализованы:

- главная страница и навигация;
- создание и редактирование черновика задачи;
- AI-уточнение, сохранение ответов и генерация карточки;
- рейтинг готовности, публикация и архивирование;
- каталог опубликованных задач с поиском и фильтрами;
- подробная карточка задачи и форма отклика команды;
- просмотр, принятие, отклонение и перевод откликов на рассмотрение;
- состояния загрузки, пустых данных и ошибок API, адаптивная верстка.

### Запуск

```bash
cd frontend
npm install
copy .env.example .env
npm run dev
```

В `.env` укажите URL backend API:

```env
VITE_API_URL=http://localhost:8000
VITE_USE_MOCK_API=false
```

Для демонстрации без backend можно временно включить `VITE_USE_MOCK_API=true`. AI API не вызывается из браузера: все AI-операции идут через backend endpoint’ы.
