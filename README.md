# AI Sana Challenge Hub — backend

Backend MVP для проекта МНВО и AI Sana. Сервис помогает бизнесу уточнить черновик задачи с помощью AI, сформировать карточку проекта, оценить её готовность, опубликовать в каталоге и принять отклики студенческих команд.

## Запуск

Нужен Node.js 20 или новее.

```powershell
npm install
Copy-Item .env.example .env
npm start
```

Сервер запускается на `http://localhost:3000`. Для генерации вопросов и карточек обязательно укажите `AI_API_KEY` в `.env`. Ключ не передаётся во frontend и не записывается в Git.

Для разработки с автоматическим перезапуском:

```powershell
npm run dev
```

## API

Служебная проверка: `GET /health`.

Основные endpoint-ы:

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/tasks` | Создать черновик задачи |
| GET | `/api/tasks` | Получить опубликованные задачи |
| GET | `/api/tasks?status=draft` | Получить задачи выбранного статуса |
| GET | `/api/tasks/:id` | Получить задачу |
| PATCH | `/api/tasks/:id` | Изменить черновик |
| POST | `/api/tasks/:id/clarify` | Сгенерировать вопросы через AI |
| POST | `/api/tasks/:id/answers` | Сохранить ответы бизнеса |
| POST | `/api/tasks/:id/generate` | Сформировать карточку и рейтинг |
| POST | `/api/tasks/:id/publish` | Опубликовать готовую задачу |
| POST | `/api/tasks/:id/archive` | Архивировать задачу |
| POST | `/api/tasks/:id/applications` | Отправить отклик команды |
| GET | `/api/tasks/:id/applications` | Получить отклики |
| PATCH | `/api/applications/:id` | Изменить статус отклика |

По умолчанию `GET /api/tasks` возвращает только задачи со статусом `published`, поэтому черновики не появляются в публичном каталоге. Для фильтрации доступны параметры `status`, `skill`, `technology` и `deadlineBefore`.

Публикация требует подтверждения:

```json
{ "confirm": true }
```

Данные MVP сохраняются в `data/db.json`. Файл создаётся автоматически и исключён из Git. При дальнейшем подключении настоящей базы данных слой хранилища можно заменить без изменения API-маршрутов.
